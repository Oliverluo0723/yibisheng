# 第二版交接：給新 session 的脈絡

> 寫於 2026-11-10，第一版（git tag `v1`）完成當天。
> 這份文件的讀者是接手第二版討論的 Claude session。使用者會用它開場，之後在那個 session 討論。

## 這是什麼專案

以 **p5.js** 為基礎的**互動視覺藝術作品**，和 **Botanica**（Petalcore）音樂類型結合。核心概念來自台灣 p5.js 藝術家 ileivoivm 的 InkField：**每一筆都被記住，畫面會繼續演化**。

形式：網頁、滑鼠、一次一位觀眾。工具：Vite + pnpm + TypeScript（strict）+ p5.js 2.x instance mode + lil-gui + Vitest + Biome。

## 第一版做了什麼

`experiments/01-growth-branch`（`pnpm dev` 後開首頁點進去）：

- 滑鼠畫一筆，筆觸存成資料（0..1 比例座標 + 毫秒時間），可匯出、匯入 JSON。
- 放開後，筆觸當主幹，沿筆觸長出幾個「芽」，用**遞迴分枝 + 雜訊**往外長，有生命、分枝深度和芽數上限。固定步長推進，同一種子可重現，不受幀率影響。
- 畫面：米白紙感背景、帶顆粒的線、低飽和植物色，Canvas 2D。
- 聲音：原生 Web Audio，每長出一個分枝響一個三角波音，音高落在 B♭ 大調（王道進行 E♭–F–Gm–B♭ 所在的調），帶回授延遲。
- 右上角 lil-gui 面板可即時調生長、畫面、聲音參數。

模組：`src/strokes`（資料）、`src/growth`（演算法）、`src/render`（畫面）、`src/sound`（`SoundEngine` 介面 + Web Audio 實作）。實驗只負責接線。測試 22 個，全綠。

## 使用者試玩第一版的回饋

1. 「**預設太快，且長太多**」→ 已調慢、調少（速度 0.08→0.03、分岔 0.25→0.12、最深 5→3、芽 6→4、上限 300→60、生命 6→9 秒）。
2. 「**成長卡頓**」→ 原因是枝條整段冒出；已改成芽尖的進行中段每幀連續畫。
3. 使用者對第一版的感覺到此為止，沒有更多形容。**第二版該先問他看了第一版之後，真正想要的是什麼。**

## 還沒決定、要靠看畫面決定的事（來自 concept.md 6.1）

- 一筆怎麼長：主幹 / 播種線 / 根（v1 用主幹）
- 生長會不會停、有沒有凋零和循環（v1 有限生長，長完就停在那裡）
- 筆觸之間要不要互動（v1 各長各的）
- 畫面基調：米白紙感 / 深色發光 / 黑白水墨（v1 米白）
- 線條質感：顆粒手感 / 乾淨（v1 顆粒）
- 聲音：生長時發聲 / 畫線時發聲 / 兩者；純合成 / 免費原聲素材 / 混用（v1 生長時、純合成）
- 生長演算法：遞迴分枝（v1）/ L-system / 雜訊漫步 / 空間殖民 / 差異生長 / **回授（feedback）**
- 作品長度、有沒有結尾（使用者說先不談）

## 已經查過、可以直接用的資料

- `docs/botanica-research.md`：Botanica 的起源、特色、製作方式、代表藝人。重點：原聲被打碎重組、反轉造成的膨脹感、保留環境雜訊、懷舊但帶希望。
- `docs/sound-libraries.md`：聲音函式庫比較。結論：正式用 **Tone.js** 核心 + **tonal** 音階 + 自寫顆粒層 + **Meyda** 分析；避開 p5.sound、Strudel（AGPL）。
- `docs/inkfield-tech-notes.md`：InkField 的技術文件筆記。重點：全靠 GPU shader、沒有多執行緒；**feedback shader 每幀把墨「推」一點**是「痕跡持續演化」最直接的實作；彈簧 + 阻尼筆刷；重播逐幀對齊；「不錄結果，錄過程」。InkField 原始碼授權未開放，只能學概念不能複製程式碼。
- Lunacy Audio 的 **Tides**（phritz、Alexander Panos 做預設音色）：六層自然錄音與樂器疊加、可反轉拉伸。

## 第二版可能的方向（都還沒和使用者確認，只是候選）

- 讓痕跡「活」起來：p5 WEBGL + framebuffer + 一支 feedback shader，墨會暈、會流。
- 彈簧 + 阻尼筆刷，讓筆觸本身有速度感。
- 聲音升級到 Tone.js，加入免費原聲片段的反轉與顆粒處理。
- 凋零與循環：長完之後慢慢褪色、碎裂，成為下一筆的養分。
- 筆觸之間的互動。

## 和使用者工作的方式（重要）

- 使用者**本來就會 TypeScript**，用繁體中文溝通。
- 發想時隨口丟的關鍵字（例如「痕跡 大自然 植物意象」）**是靈感不是定案**，不要當成決定。
- 他說「先不討論」「這要實驗才知道」就記下來往下走，不要重問。
- 問太多抽象問題他會說「我哪知道我要啥」：**他需要看到畫面才能判斷**。多做小草稿讓他反應，少問空泛的問題。
- 開始寫程式前他會要求**先 plan 再做**。
- 程式由 Claude 寫、留好調的參數；他試玩、調整、給方向。
- 審查者留下的小問題清單在 git log `18c381e` 之前的 commit 訊息與本文件沒有重複列出，見 `docs/superpowers/plans/2026-11-10-exp01-growth-branch.md` 的 Review Focus 與最終 commit。
