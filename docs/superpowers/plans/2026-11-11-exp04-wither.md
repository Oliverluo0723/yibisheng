# 04 空間：枯（跟著熱度的結尾）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 停手之後押花樹自己枯掉（葉落、枝斷、落地），再畫就回來；枯有聲音但不推熱度。

**Architecture:** 一個純的乾燥時鐘 D（`src/growth/wither.ts`）在 04 主程式裡跑，吃主程式自己持有的 `Heat`；每株記出生時的 D，算出 0..1 的 wither 推給草稿已有的 `PlantView` 狀態機。`PlantView.sync` 回傳葉落地、枝斷的事件，主程式轉給 `SoundEngine.onWither`，Botanica 引擎用顆粒與偶發層發聲、不碰熱度。

**Tech Stack:** TypeScript strict、three.js（04）、Tone.js 15（只在 `audio/`、`layers/`、`index.ts`）、Vitest、Biome。

**Spec:** `docs/superpowers/specs/2026-11-11-exp04-wither-design.md`（草稿 tag `exp04-o`）

## Global Constraints

- 純程式不 import Tone；引擎用假的層測（`engine.test.ts` 的 `fake()`）。
- 枯不依賴聲音開著：時鐘的 `activity()` 與 `tick()` 放在 `state.sound.enabled` 判斷之外。
- 預設值照 spec：寬限 25 秒、熱度門檻 0.3、全枯 100 秒；葉脫離點 0.08–0.63、枝斷點 0.5–0.98（草稿既有）。
- 枯的聲音不呼叫 `idle.activity`、不加 `heatState`。
- 每株 wither 只增不減；D 永不倒退。
- 每輪結束切 tag `exp04-p`、`docs/process-log.md` 加一列；commit 只加自己改的檔。

## Review Focus

1. **畫很長一筆的途中**園子不能開始枯：筆還沒放開也算活動（Task 1 測 `activity` 每幀呼叫時 D 不走；Task 4 在 `stepDrawing` 裡呼叫）。
2. **切到別的分頁再回來**：rAF 停了幾分鐘，回來那一幀 dt 很大。D 一次最多走 0.1 秒，不會一回來葉子全掉（Task 1 測）。
3. **關聲音、或切回舊引擎**時枯照常走（Task 4 瀏覽器驗收項）。
4. **一批葉子同一幀落地**：顆粒走每秒上限，不會機關槍（Task 2 測 20 個同毫秒的 leaf 事件最多發 `maxPerSec` 個）。
5. **枯到一半按復原／清空**：掉在地上的葉、斷枝跟著那株一起消失，沒有殘留 Mesh（Task 3 測 `dispose()` 後 `group.children.length === 0`）。

  ```ts
  export type WitherClockOpts = { graceMs: number; heatThreshold: number };
  export const defaultWitherClockOpts: WitherClockOpts = { graceMs: 25000, heatThreshold: 0.3 };
  export class WitherClock {
    constructor(opts?: Partial<WitherClockOpts>);
    /** 面板直接改這個物件 */
    readonly opts: WitherClockOpts;
    /** D，秒；只進不退 */
    get seconds(): number;
    /** 放開、分枝、長葉、畫線中：都算活動 */
    activity(nowMs: number): void;
    /** 每幀呼叫；回傳 D。距離上次 tick 的 dt 最多算 100 ms */
    tick(nowMs: number, heat: number): number;
  }
  export class PlantWither {
    constructor(bornSeconds: number);
    /** 回傳 0..1，只增不減；manual > 0 時取 max(自動, manual) */
    update(clockSeconds: number, fullSec: number, manual: number): number;
    get value(): number;
  }
  ```
