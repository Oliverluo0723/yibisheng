# Botanica 音樂類型研究筆記

> 用途：p5.js 互動視覺藝術專案的前期研究

> 可信度：Botanica 是很新的網路微型曲風（microgenre），目前還沒有權威的百科條目。本文主要根據 Splice 官方部落格，以及命名者 phritz 在 Ableton 官網的訪談，這兩者算一手來源。只出現在二手或 AI 輔助文章的說法，會標上 ⚠️。

## 1. 一句話定義

**Botanica**（又稱 **Petalcore**）是一種電子音樂微型曲風。它用鋼琴、弦樂、吉他、人聲這類帶懷舊感的原聲樂器音色，再加上頻譜處理（spectral processing）和 glitch 故障音效去切碎、重組。

- 製作人 Michael Bruner 的形容：**「就像是精靈做的 hyperpop。」**（"It's like if fairies made hyperpop."）
- 結構上比較接近 ambient 氛圍音樂，在不同質地之間自由流動，不太依賴清楚的旋律或傳統的歌曲結構。

## 2. 起源

### 2.1 時間線

| 時間 | 事件 |
|---|---|
| 2000 年代初 | 日本 folktronica / electronica（民謠電子）。phritz 認為這是 Porter Robinson《Nurture》的靈感來源，例如他提到 sora 的專輯《re.sort》 |
| 2021 | Porter Robinson 發行專輯 **《Nurture》**，被廣泛視為這種聲音的關鍵影響 |
| 2021 之後 | SoundCloud 上出現大量類似風格的作品，留言常寫「Nurture vibes」。創作者覺得被簡化成「模仿 Porter」，不夠尊重 |
| 同時期 | **phritz** 發推文提議用「Botanica」作為曲風名稱，並在 Spotify 建了一份叫「Botanica」的歌單，收錄這類音樂和它的前身。phritz 說：「這就是所謂 Botanica 的開始。」 |
| 2022 | **Alexander Panos** 發行專輯 **《Nascent》**。受它影響的創作者開始在 SoundCloud 用「**Petalcore**」標籤 |
| 之後 | Botanica 和 Petalcore 這兩股潮流合流，有些人同時標「Petalcore/Botanica」 |
| 2025–2026 | Splice 統計：Botanica 的每月搜尋量成長 **25.5 倍**，是 Splice 上成長最快的曲風 |

### 2.2 關於起源要注意的地方

- **命名時間有出入**：phritz 在 Ableton 訪談裡說是《Nurture》（2021）之後開始提出這個名稱，但沒給確切日期。另一篇 Alexander Panos 訪談的摘要則寫「2022 年底」⚠️。
- **社群**：主要的發生地是 **SoundCloud**。據說 Panos 和朋友在 2021 年開的 SoundCloud 帳號 *e-veryday*（規則是每天發一首 15 秒以內的作品），以及 2023 年由其追隨者組成的 **Novel** 創作團體，大大影響了大眾對 Botanica 的認識 ⚠️（來源是摘要，未能核對原文）。
- **定位很鬆散**：phritz 自己也說，他其實不太清楚這個類型現在的全貌。另有二手文章說他希望 Botanica 保持一個「鬆散的社群」，不要變成死板的曲風 ⚠️。
- **不要搞混**：同名的 *Botanica* 樂團（1999 年成立於洛杉磯的另類搖滾樂團）和這個曲風無關。

## 3. 音樂特色

### 3.1 聲音質地
- **原聲素材**：鋼琴、弦樂、吉他、人聲、便宜的 Casio 電子琴取樣
- **數位處理**：頻譜處理、glitch、顆粒合成造成的碎裂感
- **保留雜訊**：刻意保留錄音裡的環境音和底噪，例如蟋蟀、蟬鳴、吉他錄音裡的雜訊，營造「生的」、未經修飾的質感
- **膨脹感（swell）**：大量使用反轉的殘響和延遲，讓聲音像花苞一樣慢慢鼓起、綻放

### 3.2 速度與節奏
- **沒有固定 BPM**：
  - 偏 ambient 的作品：約 **40–70 BPM**
  - 偏流行的作品（像《Nurture》）：約 **100–160 BPM**。Michael Bruner 最喜歡 160 BPM 左右
- 速度可以不對齊網格，或用自動化做出漸快漸慢
- 節奏上偏好比較細的切分，像八分和十六分音符

### 3.3 結構
- **非線性、會突然轉變**：一首歌可能先是沒有拍子感的氛圍交響，然後突然撞進 hyperpop 風格的段落
- 有些作品完全是冥想式的，有些則接近一般流行歌的編排

### 3.4 和聲與情緒
- 情緒關鍵字：**懷舊、內省、轉瞬即逝、充滿情感**
- Bruner 的說法：「和弦進行可以非常情緒化，但轉角處通常總有一絲希望和溫暖的解決。」
- 常用「**王道進行**」（IV–V–vi–I）的變化，例如 E♭ – F – Gm – B♭，加入七和弦、九和弦增添憂鬱色彩
- 意象：自然、生長、青春、野性。Bruner 說：「這音樂感覺狂野、未被馴服……最後都回到自然。」

## 4. 如何製作

### 4.1 基本思路
> 原聲素材 → 錄下來（保留雜訊）→ 用數位手法切碎、拉長、反轉 → 層層堆疊出「會呼吸、會生長」的聲音

### 4.2 核心技法

| 技法 | 做法 | 效果 |
|---|---|---|
| **顆粒合成（Granular synthesis）** | 把一段聲音切成極小的「顆粒」再重新排列。常用 Ableton 內建的 **Granulator III** | 碎裂、閃爍的 glitch 感，也可以做段落轉場 |
| **反轉（Reverse）** | 反轉取樣；或單獨把殘響、延遲 bounce 出來再反轉；疊幾層 pad，只反轉其中幾層 | 聲音慢慢膨脹、綻放的感覺 |
| **頻譜處理** | 用 Spectral Suite 這類外掛處理頻譜 | 夢幻、失真、像水面倒影的音色 |
| **共振峰（Formant）移動** | 用 MAutoPitch 這類工具，自動化改變人聲或樂器的「喉嚨長度」 | 聲音在像人和不像人之間游移 |
| **極端拉伸** | 用 PaulXStretch 把短錄音拉成長長的持續音（drone） | 氛圍底層 |
| **田野錄音** | 用手機或筆電麥克風錄環境音，再丟進 DAW 塑造成 loop、drone、打擊樂 | 有機、自然的質感 |

### 4.3 phritz 的實際做法（取自 Ableton 訪談）
1. 把鋼琴或人聲等原聲素材放進 **Granulator III**
2. 對 **Position** 參數做調變或自動化，讓聲音變得更有攻擊性
3. bounce 成音訊 → 加效果 → 切片重組
4. 用**多頻段側鏈**效果器組（Multiband Dynamics + Compressor）讓高、中、低頻分別隨鼓聲「呼吸」
5. 另一條效果鏈：正弦波撥弦音 → Redux（降位元）→ PitchLoop89（音高延遲）→ Beat Repeat → Auto Pan
6. 自製 Max for Live 工具：
   - **Sequence on Trigger 16**：每收到一個 MIDI 訊號，就把 Granulator 的播放位置推進一格
   - **Random on Trigger**：隨機切片
   - **shoal**：模擬 Fairfield Circuitry「Shallow Water」效果器（帶包絡跟隨的低通濾波，再加失真）

### 4.4 常用工具

| 類別 | 工具 |
|---|---|
| DAW | Ableton Live（社群最常用） |
| 原聲音源 | Spitfire Audio 音源庫、XLN Audio Addictive Keys（用比較柔和的設定） |
| 頻譜處理 | **Spectral Suite**（免費，「在 Botanica 社群被奉為神器」）、CYCLES（Slate & Ash，偏貴） |
| 失真與劣化 | SpecOps（Unfiltered Audio） |
| 音高與共振峰 | MAutoPitch（Melda，免費） |
| 拉伸 | PaulXStretch |
| 取樣包 | Splice 上的 *Vocal Botanica*（Michael Bruner）、*Resonance Botanica, a phritz Moment*、*Serum 2 Botanica*、*Botanica Essentials*、*Lakeshore Afterimage*（Alexander Panos） |

> Bruner：「這些外掛都不是必要的，DAW 內建效果就能做出很多東西。」

### 4.5 入門學習方式（Bruner 的方法）
建一份自己的 Botanica 歌單 → 記下喜歡的段落 → 看教學影片 → 開始錄自己的聲音並實驗。

## 6. 對 p5.js 視覺作品的啟發（初步發想，待討論）

把 Botanica 的音樂特色對應到可以視覺化的概念：

| 音樂特色 | 可能的視覺轉譯 |
|---|---|
| 原聲 × 數位碎裂 | 手繪感的植物線條，被像素化、切片、錯位打斷 |
| 顆粒合成 | 粒子系統：花瓣或孢子由無數微粒組成，會散開、重組 |
| 反轉造成的膨脹 | 花苞慢慢鼓起再綻放；倒放的生長動畫 |
| 非線性、突然轉變 | 平靜的生長狀態突然切換成高能量、閃爍的段落 |
| 保留環境雜訊 | 底層的紙張紋理、雜訊（noise）、顆粒感 |
| 懷舊與溫暖的解決 | 柔和的粉彩配色，最後總回到溫暖的色調 |
| 自然、生長、野性 | L-system 分形植物、遞迴枝枒、藤蔓沿著游標生長 |
