每給使用者看一輪就打一個 git tag，並在這裡記一列。

想回到某一輪：

```sh
git checkout exp02-a   # 換成想看的 tag
pnpm install           # 那一輪的套件若不同才需要
pnpm dev
git checkout main      # 看完回到最新
```
