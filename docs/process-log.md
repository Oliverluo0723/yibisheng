# 過程紀錄

每給使用者看一輪就打一個 git tag，並在這裡記一列。

想回到某一輪：

```sh
git checkout exp02-a   # 換成想看的 tag
pnpm install           # 那一輪的套件若不同才需要
pnpm dev
git checkout main      # 看完回到最新
```

| tag | 日期 | 實驗 | 這一輪做了什麼 | 使用者的反應 |
|---|---|---|---|---|
| `v1` | 2026-11-10 | 01 畫一筆，它會長 | 筆觸當主幹長出遞迴分枝；米白紙、顆粒線；分枝時發 B♭ 大調三角波音 | 太快、長太多（已調）；生長卡頓（已修）。想要多種筆刷、要有顏色、真實紋理貼圖 |
