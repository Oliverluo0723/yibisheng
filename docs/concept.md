## 1. 已確定的元素

| 元素 | 內容 |
|---|---|
| 媒材 | **p5.js** 為基礎的視覺藝術作品 |

### 1.1 第一輪問答決定的事項（2026-11-10）

| 項目 | 決定 |
|---|---|
| 作品目的 | 個人作品集兼自我探索，可以放心實驗 |
| 觀眾的角色 | **園丁**：畫下一筆就像播種，之後放手看它自己長 |
| 第一個「演化」形式 | **生長**：筆觸像枝條一樣長出分枝和葉子（重播、流動、衰變以後再試） |
| 畫面具體程度 | **抽象有機**：有植物的生長感，但不畫具體的花草 |
| 開發順序 | **先做視覺**，第一版就附上最簡單的聲音，確認兩者連得起來 |
| 分工 | Claude 寫小實驗，並留下好調的參數；使用者試玩、調整、給方向 |
| 工具 | **p5.js**。TouchDesigner 只當靈感來源，它的手法（回授、雜訊位移、粒子、聲音反應）翻譯成 p5.js 來做 |

> 「演化」的候選形式加上 **Feedback（回授）**：把上一格畫面略為縮放、旋轉、模糊後疊回來，讓舊痕跡一層層擴散、暈開。這是 TouchDesigner 常見的手法。

### 1.2 專案架構（架構問答，2026-11-10）

| 項目 | 決定 |
|---|---|
| 建置工具 | **Vite + pnpm**（函式庫用 pnpm 安裝，版本記在 `package.json`） |
| 語言 | **TypeScript**（使用者本來就熟悉 TS） |
| p5.js 寫法 | **Instance mode**（`new p5((p) => { ... })`），才能搭配模組化 |
| 程式結構 | 共用模組放在 `src/`，按功能分成筆觸、生長、畫面、聲音、介面；**每個實驗只寫自己特有的部分**，用 `import` 組合 |
| 記憶的存法 | **筆觸存成資料當本體**（每一點的位置和時間），畫面、生長、聲音都從資料產生；回授等畫面效果疊在上面 |
| 參數面板 | **lil-gui** 滑桿面板，可以即時調整，也能存成預設 |
| 聲音函式庫 | 調查結論見 [sound-libraries.md](sound-libraries.md)：建議 **Tone.js** 當核心、**tonal** 管音階、顆粒與頻譜處理自己寫、**Meyda** 做分析。實驗 01 先用原生 Web Audio，之後透過 `SoundEngine` 介面替換 |
| 版本紀錄 | **Git**，先只存在本機，要不要上傳 GitHub 之後再決定 |
| p5.js 版本 | **2.x**（目前 2.3.4，內建型別） |
| TypeScript | `strict: true` |
| 格式化與檢查 | **Biome** |
| 測試 | **Vitest**，只測不用看畫面就能判斷對錯的部分（筆觸資料、生長規則）；畫面靠實驗和使用者判斷 |

| 聲音模組 | 定義統一的 `SoundEngine` 介面，實際用哪個函式庫藏在介面後面，可以替換、混用 |
| 音檔管理 | 放在 `public/sounds/`，另用一份清單記錄每個檔案的來源、作者、授權，公開作品時用來產生致謝名單 |
| 筆觸存檔 | 可以匯出、匯入 JSON，格式帶版本號 |
| 畫布 | **填滿瀏覽器視窗**，跟著視窗大小調整；筆觸座標存成 0 到 1 的比例，換視窗大小重播也不會跑位 |
| 實驗目錄 | 專案首頁列出所有實驗，每個附一句說明和連結 |

```ts
// 筆觸資料的初步形狀
type StrokePoint = { x: number; y: number; t: number }; // x、y 是 0 到 1 的比例；t 是從這一筆開始經過的毫秒數
type Stroke = { id: string; startedAt: number; points: StrokePoint[] };

// 匯出的 JSON
// { "version": 1, "canvas": { "width": 1920, "height": 1080 }, "strokes": [ ... ] }

interface SoundEngine {
  start(): Promise<void>;               // 瀏覽器規定要等使用者互動後才能出聲
  onStrokePoint(p: StrokePoint): void;  // 畫線時
  onGrowth(event: GrowthEvent): void;   // 生長時
}
```

## 3. 參考作品

### 3.1 InkField（墨域）— ileivoivm（Aluan Wang）
- 網址：https://ileivoivm.github.io/inkField/
- 什麼：用 p5.js 加 WebGL shader 做的數位水墨繪畫系統
- 作品自述：「保存繪畫行為本身的系統，每個手勢都被記住，每張畫都持續演化。」
- 觀察到的特徵：
  - 筆觸邊緣有乾筆顆粒感，收筆會散成墨點（飛白）
  - 7 種筆刷、6 種墨效（飛、壓、麥、鹽、染、毛）
  - 流動效果（漩渦、花形、波紋）、金屬光澤，以及扭曲、細胞紋理、顆粒等後製效果
  - 把每個手勢錄成 JSON，之後可以重播成隨時間展開的生成藝術
- **最吸引我們的部分**：每一筆都被記住，畫面會繼續演化（概念層面，不是水墨質感）

### 3.2 Tides — Lunacy Audio
- 網址：https://lunacy.audio/products/tides/
- 什麼：商業虛擬樂器「Botanical Loop Lab」，售價 99 美元，可以在瀏覽器裡試玩
- 和 Botanica 的關係：預設音色由 **phritz**（Botanica 命名者）和 **Alexander Panos** 製作
- 觀察到的特徵：
  - 最多六層 loop 和樂器疊加
  - 每一層可以反轉、拉伸、移調、濾波、淡入淡出
  - 素材有大自然錄音（瀑布、風鈴、樹葉、雷雨），也有弦樂、豎琴、卡林巴琴、人聲
  - 用「bloom（綻放）」形容聲音
- **可借鏡的部分**：分層疊加的聲音結構；大自然錄音和原聲樂器並用

## 4. 參考作品能不能逆向工程？

| | InkField | Tides |
|---|---|---|
| 原始碼 | 網頁上看得到，但授權明定**還沒開放** | 商業閉源產品 |
| 可以做的 | 為了**個人學習**閱讀、clone 原始碼；用它的網頁版創作 | 試玩免費的瀏覽器版、看官方介紹和教學影片 |
| 不可以做的 | 把程式碼、shader、渲染引擎搬進自己的作品；或做成衍生程式 | 拆解它的程式和音色樣本來使用 |
| 建議做法 | **學概念，自己重寫**：例如「把手勢錄成資料再重播」這個想法，用自己的程式實作 | **學結構，自己做**：用免費素材和瀏覽器音訊重現「分層、反轉、拉伸」的手法 |

> InkField 授權原文（摘要）：可以為個人學習而閱讀和 clone；重新散布、分叉成另一個產品、把渲染引擎整合進其他應用程式、建立衍生程式，都保留權利。作者表示，將來停止維護時會改用開源授權。

## 5. 聲音策略（初步）

| 方式 | 做法 | 優點 | 限制 |
|---|---|---|---|
| 程式合成 | p5.sound 或 Tone.js 即時產生聲音 | 能跟筆觸直接連動，不需要音檔 | 很難做出鋼琴、人聲那種溫暖的原聲質感 |
| 免費素材 | 例如 Freesound 的田野錄音、樂器片段 | 有原聲和自然的質感 | 要逐一確認授權（CC0、CC-BY、是否可商用） |
| **混用（我的建議）** | 拿免費的原聲片段當素材，再用程式即時反轉、拉伸、切成顆粒 | 這本身就是 Botanica 的製作方式 | 實作比較複雜 |

### 6.1 要看到畫面才能決定的問題（第二輪問答，暫緩）

這幾題沒有畫面很難判斷，改用實驗決定。括號裡是 Claude 的初步建議，還沒定案。

- 一筆怎麼長：當主幹／播種線／根（建議：主幹）
- 生長會不會停：有限／無限（建議：有限）
- 筆觸之間的關係：各長各的／會互動（建議：先各長各的）
- 畫面基調：米白紙感柔和色／深色發光／黑白水墨（建議：米白紙感）
- 線條質感：有顆粒的手感／乾淨平滑（建議：手感）
- 第一版的聲音：生長時發聲／畫線時發聲／兩者都有（建議：生長時）
- 生長演算法：遞迴分枝、L-system、雜訊漫步、空間殖民、差異生長、回授（建議：先試遞迴分枝加雜訊）
