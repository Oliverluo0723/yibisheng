# InkField 技術文件筆記

> 來源：https://ileivoivm.github.io/inkField/tech/ 及其子頁（effects、recording、ink-effects、brush-physics、ai-json-generation）
> 整理日期：2026-11-10
> 注意：InkField 原始碼授權尚未開放，這裡只記錄**公開文件描述的概念**，不複製程式碼。文件是給一般讀者的教學，各頁名稱和數字偶有不一致。

## 一句話

筆觸先畫成灰階草稿，再經過一連串 GLSL 著色器；每一幀把墨水「推」一點點，所以畫面會持續演化。

## 1. 渲染架構

- 技術棧：p5.js（WEBGL 模式）、GLSL、p5.easycam。約 10,871 行 JS、2,775 行 GLSL、10 支自訂 shader。
- **沒有多執行緒**：文件完全沒提 Web Worker、OffscreenCanvas、WebGPU。速度來自把像素工作交給 GPU shader。
- 管線：筆觸輸入 → `encode`（35 色查表 + HSB）→ `typeMapEncode`（逐像素記錄筆刷類型）→ `feedback`（6 種墨水物理）→ `flow`（8 種噪聲位移）→ `composite`（依筆刷類型選混合模式）→ `distort`（FBM / 共振波 / 細胞 / 白點 / 顆粒）→ 螢幕。另有 `realtime`（畫的當下預覽）和 `metallic`（金屬光澤後製）。
- **14 個 Framebuffer + 13 個 createGraphics**，全部共用主畫布的 GL context。從原本 16 個 context 減到 3 個之後，Safari 從約 10 FPS 變流暢。
- 行動裝置自動把 pixel density 降到 1.0。

## 2. 回授（feedback shader）：墨為什麼會動

每一幀做三件事：
1. 讀「力場地圖」（forceMap，0.5 代表無風；實際風力 = (值 − 0.5) × 強度）
2. 把墨往風的方向推一點：`結果 = min(原位置的墨, 偏移位置的墨)`，`min` 保證墨只會擴散、不會無中生有
3. 加上質感：hash 雜訊 `fract(sin(n) × 43758.5453)`，分成低頻（2–15，水漬）、中頻（30–80，纖維）、高頻（100–400，顆粒）、超高頻（400–600，細斑）

六種墨效（飛白、擠壓、麥克筆、鹽巴、暈染、毛）差別只在：擴散方向、取樣幾個鄰居、用哪些頻率層的雜訊、邊緣是加深還是變亮。

## 3. 筆刷物理：彈簧 + 阻尼

- 畫筆被滑鼠「拉著走」：加速度 += (滑鼠 − 畫筆) × 彈力；加速度 ×= 阻尼；位置 += 加速度。預設彈力 0.5、阻尼 0.5。
- 速度越快線越細：目前粗細 = 基本粗細 − 速度。
- 收筆漸細：每幀 −0.05，最細 1。
- 作者的話：七種筆法不是刻意做的，「設計了一個好的物理模型，這六種效果就自然浮現了」。

## 4. 錄製與重播

- JSON 事件：`m`（mp/md/mr/kp/ec）、`t`（毫秒）、`x`、`y`；`mp` 帶完整的 strokeData 快照（35+ 欄位）。縮寫是為了省空間：一幅畫幾萬個事件，只有幾十 KB。
- **重播是逐幀推進，不是照時間戳**：一幀只處理一個拖曳事件，因為筆刷物理每幀算一次，畫的次數要和錄的時候一樣。錄製時的 FPS 就是路徑點密度。
- 停頓會被壓縮；放開筆後至少等約 30 幀再開始下一筆，否則上一筆的收尾會被切掉。
- 亂數：種子 + 計數器（Crandom），重播時比對 random() 呼叫次數找出分歧點；移除所有「條件式隨機」讓呼叫次數穩定；重現率 99.9%。
- 重播前把所有狀態重置：畫布、種子、筆刷、特效、力場、shader、相機。

## 5. 其他特效（概念）

- **Flow**：對畫面做噪聲位移，取 `min(原位置, 偏移位置)` 把墨拉過來；邊緣用 dither 產生飛白。8 種樣式：同心圓、縱向、橫向、龜裂、馬賽克、漩渦、細胞。
- **Bugs（蟲咬）**：掃描畫面暗部，加權隨機選 10 個點，長出程序化的有機形狀（圓、矩形、閃電、大閃電），模擬版畫的蝕刻。
- **Metallic**：從遮罩梯度算法線，加 Fresnel 反光；六種色調（金、銀、銅、玫瑰、黑金、鑽石，鑽石有三色色散）。
- **後製**：FBM 扭曲 → 共振散射（16 個波源）→ 細胞紋理 → 白點（三層大小）→ 底片顆粒。
- 共同原則：「不改變原始筆觸，只改變它被看到的方式」。

## 6. 設計哲學（作者原話）

- 「Drawing is not an image. It is an event.」
- 「InkField 將繪畫從『圖像』轉回『行為』。」
- 「不錄結果，錄過程。不靠運氣，靠種子。不一次多做，一次一步。不忽略細節，全部重置。」
- 「共繪不是『AI 幫我填滿畫布』，而是『AI 回應我這一筆』。」

## 7. 對我們專案的啟示

| InkField | 我們的對應 |
|---|---|
| 手勢存成 JSON、種子亂數 | 已經是這樣做（`src/strokes`、`mulberry32`） |
| 逐幀推進而非照時間戳 | 我們目前生長用 `deltaTime`，若之後要精確重播，考慮改成固定步長 |
| feedback shader 讓墨持續演化 | 下一個實驗可試 p5 WEBGL + `createFramebuffer()` + 一支 feedback shader；生長演算法不用改 |
| 彈簧 + 阻尼筆刷 | 可以加在 `StrokeRecorder` 之後、畫線之前，讓筆觸有速度感 |
| 共用 GL context、少開 buffer | 若走 WebGL，用 framebuffer，不要開很多 createGraphics |
| 顆粒用 shader 雜訊 | 取代目前 CPU 畫三次抖動線 |
